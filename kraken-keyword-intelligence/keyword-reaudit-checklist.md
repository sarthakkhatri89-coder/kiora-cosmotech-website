# Keyword Re-Audit Checklist

## Live vs Code

- [ ] Homepage title and H1 still match the umbrella commercial keyword.
- [ ] Private label title, H1, intro, and FAQs clearly own the private-label cluster.
- [ ] Skincare manufacturer page acts as a category hub rather than duplicating private-label intent.
- [ ] Third-party and contract pages are visibly differentiated in headings and intro copy.
- [ ] Hair serum live route and shared source language now align.

## Metadata

- [ ] Titles are unique.
- [ ] Meta descriptions are unique and commercially aligned.
- [ ] Canonicals are self-referencing and correct.

## Headings and Copy

- [ ] One H1 per page.
- [ ] First 100 words support the target keyword naturally.
- [ ] FAQ questions match real buyer intent.
- [ ] No keyword stuffing introduced.

## Internal Links

- [ ] Blog posts link to the correct primary commercial page.
- [ ] Product pages link to relevant service and quote pages.
- [ ] Packaging and quote pages receive enough internal support.

## AEO / GEO / Answer Readiness

- [ ] Direct-answer blocks exist where recommended.
- [ ] Quote requirements are answered clearly.
- [ ] Packaging options are answered clearly.
- [ ] Manufacturing process/timeline questions are answered clearly.

## Cannibalization

- [ ] Private label vs skincare overlap is reduced.
- [ ] Third-party vs contract overlap is reduced.
- [ ] Manufacturing guide blogs no longer read like duplicate money pages.

## Validation

- [ ] Build passes.
- [ ] Live deployment reflects source changes.
- [ ] Search Console review is scheduled when data becomes available.
