# KRAKEN DEEP AUDIT - Re-Audit Checklist

## Conversion
- [ ] Quote form submits to a real destination
- [ ] Error handling works when submission fails
- [ ] Success state or thank-you page works
- [ ] Quote submission event is tracked

## Analytics
- [ ] GA4 or GTM is installed
- [ ] WhatsApp clicks are tracked
- [ ] Phone clicks are tracked
- [ ] Primary CTA clicks are tracked
- [ ] Search Console verification is confirmed

## Domain / Canonicals
- [ ] Canonical URLs use the intended primary domain
- [ ] Robots host uses the intended primary domain
- [ ] Sitemap URLs use the intended primary domain
- [ ] JSON-LD URLs use the intended primary domain

## Trust / EEAT
- [ ] Privacy Policy page exists
- [ ] Terms & Conditions page exists
- [ ] Footer links to trust pages
- [ ] Quote page includes basic privacy reassurance
- [ ] Commercial pages include stronger visible trust blocks

## Schema
- [ ] Shared product pages include richer schema coverage
- [ ] Shared content pages include richer page-level schema where appropriate
- [ ] Hair serum page no longer emits duplicate Service schema
- [ ] FAQ schema appears only where FAQs are visible

## Metadata
- [ ] Hair serum title is shortened
- [ ] Hair serum meta description is shortened
- [ ] Face wash meta description is within target range
- [ ] Sunscreen meta description is within target range
- [ ] Long blog descriptions are trimmed where needed

## Blog EEAT
- [ ] Author/editorial note appears on article pages
- [ ] Updated date remains visible
- [ ] Article schema matches visible content

## Performance
- [ ] Long product page HTML payloads are reduced where practical
- [ ] No essential crawlable content is hidden
- [ ] Hero images remain optimized and render correctly

## Technical Validation
- [ ] `next build` passes
- [ ] Lint runs non-interactively
- [ ] Sitemap still includes correct URLs only
- [ ] Robots file is still valid
- [ ] No broken internal links on key pages
